# Sprout Garden · Sight Words

5~7세 아동을 위한 사이트워드(Sight Words) 학습 앱 프로토타입입니다. 단일 HTML 파일로 되어 있으며, 별도 설치나 서버 없이 브라우저에서 바로 열립니다.

## 대상 및 목적

- 대상: 만 5~7세, 아직 글을 유창하게 읽지 못하는 아동
- 목적: 소리·그림·인쇄된 글자를 함께 노출시켜 자주 쓰는 사이트워드를 자연스럽게 익히기
- 텍스트보다 음성(Web Speech API)과 아이콘을 우선해, 글을 몰라도 혼자 진행할 수 있도록 설계했습니다.

## 레벨 3단계와 피드백 설계

레벨은 발달 단계에 맞춰 **오답 시 피드백 방식 자체가 자동으로 달라지도록** 설계했습니다.

| 레벨 | 대상 | 오답 시 반응 |
| --- | --- | --- |
| 🌱 Sprout (Basic) | 5세~ | 틀렸다고 말하지 않고 항상 격려만 함. 선택지가 계속 활성 상태라 부담 없이 다시 시도 가능 |
| 🌳 Tree (Intermediate) | 6세~ | 1차 오답 시 단어를 한 번 더 들려줌(암시적 교정) → 2차 오답 시 정답과 뜻을 문장으로 알려줌(명시적 교정). 힌트 버튼으로 첫 글자를 미리 볼 수도 있음 |
| 🍎 Fruit (Advanced) | 7세~ | 정답을 바로 알려주지 않고 첫 글자(소리)만 살짝 제시해 스스로 찾도록 유도 |

정답을 알려줄 때는 `"see"는 "보다"라는 뜻이에요.` 형식의 존댓말 문장으로 통일했고, 영어 단어에 붙는 조사(은/는)는 실제 발음 기준으로 자동 판별합니다.

## 학습 모드 4가지

1. **Meet the Words** — 카드를 넘기며 단어·그림·예문·뜻을 보고 듣기
2. **Listen & Tap** — 소리를 듣고 보기 중 맞는 단어 고르기 (청각 → 인쇄 매칭)
3. **Word Hunt** — 화면에 크게 제시된 단어와 같은 낱말을 여러 개 섞인 칸에서 모두 찾기 (인쇄 → 인쇄 시각 변별)
4. **Memory Match** — 같은 단어가 적힌 카드 두 장을 뒤집어 짝 맞추기

## 단어 목록

레벨별로 8개씩, 총 24개의 사이트워드를 담았습니다 (Dolch 목록을 참고해 임의로 구성). 실제 교재/커리큘럼에 맞춰 코드 내 `WORDS` 객체의 단어를 교체할 수 있습니다.

## 화면 구성

- 왼쪽: 레벨 선택, 학습 화면
- 오른쪽: 오늘의 기록 패널 (모은 별, 격려·다시 들려주기·설명 제공 횟수)
- 상단 "🏠 Home" 버튼으로 언제든 처음 화면으로 이동

## 기술 메모

- 순수 HTML/CSS/JavaScript 한 파일 (프레임워크 없음)
- 음성 출력: 브라우저 내장 `speechSynthesis` API (기기·브라우저에 따라 음질/지원 차이 있음)
- 라이트/다크 모드 자동 대응
- 별도 서버나 로그인 없이 파일을 열면 바로 실행됨

## 남은 과제

- 실제 사용 커리큘럼에 맞춘 단어 목록 교체
- 발음 인식(음성 채점) 등 추가 기능 여부 검토
- 아이패드/폰에서 "홈 화면에 추가"로 앱처럼 아이콘 생성 가능 (사파리 공유 버튼 사용)# -jeyoonjeong
